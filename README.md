# Painel Eleições 2026
1. Envie todos estes arquivos ao repositório GitHub.
2. Em Actions, execute **Atualizar candidatos TSE** uma vez.
3. Em Settings > Pages, publique a branch `main` pela raiz.
4. A Action atualiza a base a cada 6 horas.
Fonte dos dados: TSE / DivulgaCandContas.

## Modo TV
Marque candidatos com ⭐ e clique em **📺 Modo TV**. A seleção fica salva no navegador. Use **⛶ Tela cheia** para exibição na TV.
